## 💡 مميزات السكريبت

* 🔄 **سحب آلي بالكامل:** يتنقل بين التصنيفات والأيام ويسحب البرامج دون أي تدخل يدوي.
* 📜 **دعم Scroll التلقائي:** يتجاوز مشكلة التحميل الكسول (Lazy Loading) بالموقع عبر التمرير الذكي.
* 🛡️ **حماية البيانات:** لا يستبدل الملفات القديمة إلا بعد التأكد من صحة واكتمال السحب الجديد.
* 📺 **دعم المشغلات:** يولد ملف `epg.xml` قياسي متوافق مع كافة مشغلات IPTV (TiviMate, IPTV Smarters, Kodi, etc).

## 🚀 طريقة التشغيل والأستخدام

### 1️⃣ التثبيت (لأول مرة فقط)

قم بتثبيت المكتبات المطلوبة بفتح الترمينال وتشغيل الأمر:

```bash
pip install playwright
playwright install
```

---

### 2️⃣ التشغيل والسحب

قم بتشغيل السكريبت عبر الأمر التالي:

```bash
python epg.py
```

---

### 3️⃣ ربطه بالمشغل (طريقة الاستخدام)

1. بعد اكتمال التشغيل، سيتم إنشاء ملف باسم **`epg.xml`**.
2. قم بنسخ رابط الملف (سواء محلياً أو بعد رفعه على GitHub / سيرفر خفتي).
3. **أدخل الرابط في خيار (EPG URL) مباشرة داخل تطبيق المشغل الخاص بك واستمتع! 🎉**
